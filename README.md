# Nada Mohammed Elsayed — Portfolio

A responsive personal portfolio website built with HTML5, CSS3,
Bootstrap 5, and JavaScript.

## About

This portfolio introduces my background, technical skills,
education, and web development interests.

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features

- Responsive layout
- Personal introduction
- Skills section
- Projects showcase
- Education section
- Contact section

## How to Run

1. Download or clone the repository.
2. Open index.html in your browser.
3. Make sure you have an internet connection to load Bootstrap
   and Google Fonts.

## Before Publishing

Replace the example email and social profile links with your own.
Review the project descriptions and education details for accuracy.
